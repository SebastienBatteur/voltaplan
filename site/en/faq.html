General

Is Voltaplan free?

Yes, entirely: no subscription, no ads, no locked features. Saving and the PDF file are included, with no watermark and no project limit. Donations are optional and unlock nothing.

Link to this question

Is it open source? Under which licence?

Yes. The code is published under the GNU AGPL v3 licence on the GitHub repository. Any modified version that is distributed or offered online must publish its source code.

Link to this question

Do I need to create an account?

No. Voltaplan has no account and no server. If you choose to save to Google Drive, OneDrive, Dropbox or GitHub, you sign in to your account with that service, directly from the app.

Link to this question

Browser or desktop app?

The web version runs in Chrome, Edge or Firefox, with nothing to install. Your browser can install it as an app on a computer, iPhone, iPad or Android device (see Install). A desktop app for Windows, macOS and Linux is planned, but no desktop version has been published yet: the installers will appear on the repository's Releases page.

Link to this question

Does it work offline?

Yes, after the first visit: drawing, plan, board, calculations, RGIE check, PDF file, files and local versions work without Internet. Offline, the online AI, GitHub, Drive, OneDrive and Dropbox are unavailable; saves to these services are queued. The photo reading engine (≈ 18 MB) is downloaded the first time you read a photo, and then works offline too.

Which languages?

The app and this website are available in French, Dutch, English and German. PDF import also recognises files written in these four languages.

Using the app

How do I start a new project?

On the My projects screen, click New project, or Survey an existing installation for an installation that is already in place. The wizard has 4 steps: Type (new or existing installation, project name; for a new installation, start from an Empty project or a Typical house, to adapt), Site (client and address), Installer and Supply (voltage, earthing system, rating of the main breaker). Create now skips the remaining steps: everything can be completed later in the Project tab. To pick up a file from other software, see Which files can I import? Details: Getting started.

Link to this question

How do I draw the single-line diagram?

You do not draw it: you describe the installation in the Installation tree on the left, and the single-line diagram draws itself.

  1. Select the element to add under (board, RCD, circuit breaker…).
  2. Add with the ＋ at the end of its row, the ＋ Add… button in the properties, the Elements palette, or right-click its symbol → Add to. Only what can be connected there is offered.
  3. Example of a socket circuit: board → protective device (20 A circuit breaker) → cable (VOB 3G2.5) → sockets.

The RGIE numbering (A, B… then A1, A2…) follows. See Describing the installation.

Link to this question

How do I move, duplicate or delete an element? And undo?

Select the element in the tree, the single-line diagram, the plan or the board: it is selected everywhere. Under its properties, ↑ and ↓ change its place among its siblings, Duplicate makes a copy and Delete removes it (Del key). On the plan and in the board, drag it to move it. Undo (Ctrl+Z) and Redo (Ctrl+Y) are in the top bar. See The screen.

Link to this question

Where do I set the cable, cross-section, rating or RCD sensitivity?

In the Properties panel, under the tree, once the element is selected. Protective device: device, rating, poles, curve, breaking capacity, RCD sensitivity and type, number of modules. Cable: type (VOB, XVB…), cross-section, number of conductors, installation method, length. Also fill in the Location (the room): it is used to place the points on the plan. See Describing the installation.

Link to this question

What does the ⟳ Update button do?

Click it after creating the installation or adding circuits. It places new devices in the first free slot of the board, without moving the others, and new points on the plan near their room name; it estimates cable lengths, adds a revision to the file and recalculates numbering, labels, materials and the check. The result window lets you undo it all at once. See Update.

How do I import a background plan and set its scale?
  1. Floor plan tab → Background plan (photo / PDF / DXF)…. A DXF that states its unit is placed to scale straight away.
  2. For a photo or a PDF: Set scale, click two points and enter their real distance. Straighten (4 corners) corrects a photo taken at an angle.
  3. Draw the walls, doors and windows over it, or try Trace walls (automatic detection, to check).

See Layout plan.

How do I place points on the plan and link them to the diagram?

For an element already in the single-line diagram: Place on plan in its properties, or the palette's Not yet on the plan list, then click on the plan. For a new element: right-click the plan where you want it, choose the element, then where it connects in the single-line diagram (Voltaplan suggests the circuit of the nearest element); it is added to the diagram and placed on the plan. Drag a symbol to move it. See Layout plan.

How do I equip a whole room at once?
  1. Name the room on the plan with the Text tool (“Bedroom”, “Kitchen”, “Bathroom”…), or read the names written on the background with Read room names.
  2. Select that name: the Equip the room panel offers the usual equipment, to tick, and Add typical furniture.
  3. Add to the room places the points, not connected: then link them to their circuits.

It is a starting point, not an RGIE list. See Layout plan.

Link to this question

How do I arrange the board?

In the board's properties, set the number of rows and modules per row. In the Board tab, drag devices between the rows and the reserve, or click Automatic layout (tree order); each device's real width is set in its properties (modules). With a photo taken from the front: Board photo…, then Align photo (rows), then Arrange from photo or Compare with photo. See Distribution board and Board photo.

Link to this question

How do I use the RGIE check?

Open the RGIE check tab (the red number = number of non-conformities). Each finding has a status (non-conformity detected, insufficient information, recommendation…), a severity and, where relevant, the blocking mark.

  • A finding's Single-line, Plan and Board buttons show the element concerned.
  • When the fix is obvious, a button under the finding offers it (for example Choose 20 A); Ctrl+Z takes it back.
  • Existing installation: an element that is not drawn (earth, RCD) is confirmed with Confirm present, Confirm absent or I don’t know.
  • Derogation… records a derogation with its reason: the finding stays visible but is no longer blocking.

See RGIE check.

Where do I enter measurements?

Project tab, Measurements section: earth resistance, insulation, equipotential bonding, test of each RCD, date and measuring instrument. They are checked and printed in the file. See Measurements.

How do I get the bill of materials and cable lengths?

Materials tab: materials are grouped and added up; By room sorts them room by room. Estimate lengths calculates cable lengths from the plan (place the board on the plan first); a length you entered is never replaced. Export (CSV, spreadsheet) and Circuit list (CSV) open in a spreadsheet. See Bill of materials and How are cable lengths estimated?

How do I save, reopen or recover a project?
  • Save (Ctrl+S). Save as… chooses the location: This device (.voltaplan file), the browser or GitHub (under Other locations), or Drive, OneDrive, Dropbox.
  • Reopen: the list on the My projects screen, File → Open… (Ctrl+O) or Open from the cloud or the browser.
  • Recover: after an unexpected close, unsaved work is offered when you reopen (Recover). File → Local versions… reopens an earlier version as a new project.

See Saving and opening.

How do I change the language?

With the language selector in the top bar (Français, Nederlands, English, Deutsch); on a small screen, in the ⋯ menu → Language. The choice is remembered on this device.

What are the keyboard shortcuts?

Ctrl+S save, Ctrl+Shift+S save as, Ctrl+O open, Ctrl+P print / PDF, Ctrl+Z and Ctrl+Y undo and redo, Del delete the selected element, Esc exit the current tool. In the tree: arrows to browse, left and right to collapse and expand, + to add inside. On a Mac, Cmd replaces Ctrl. See Shortcuts.

Files

Where are my files stored?

Wherever you choose: on your device (a .voltaplan file, also on a USB stick or in a synced folder), in the browser, or in your own online storage: OneDrive, Google Drive, Dropbox or GitHub. No Voltaplan server ever receives your projects. Projects kept in the browser are erased if you clear its data: keep a file copy too. See Saving and opening.

Link to this question

Is the file format open?

Yes. A .voltaplan file is an ordinary ZIP archive: the project model as readable JSON (project.json), the original photos and PDFs as they are, and a README explaining how to recover the data without Voltaplan. The format is described in docs/file-format.md. You can also export for Trikker (.trik), Eendraadschema (.eds) and as CSV.

Link to this question

Which files can I import?

File → Import from other software… (or the card on the My projects screen) recognises the source from the content, whatever the extension: Voltaplan project, Trikker (.trik), Volter (.vschema), Eendraadschema (.eds), Draadwijs, PlanElec Sketch, Condui (.zip export) and PDF files from other software. A .zip archive containing one of these files is opened. An unrecognised file is refused with an explanation. Details: Import from other software.

Link to this question

Can I take over a PDF file made with other software?

Yes, if it contains text: circuit table, sub-boards, points, plans (as background, with walls, doors and windows read from the drawing), board front view, title block information and measurements are taken over. The PDF is read in your browser, with no upload and no AI. A scanned PDF, or one whose text is drawn as images, cannot be read: it is refused with an explanation. What the text does not say is flagged when the file opens, for you to complete.

RGIE and inspection

Does Voltaplan replace the approved inspection body?

No. Voltaplan is an aid for drawing and checking: it is not an inspection body and issues no certification, attestation or conformity report. “No anomaly detected” only means that no anomaly was found among the rules actually checked, with the information entered. You remain responsible for the installation and the documents you sign; the inspection is still carried out by the approved body. See the terms of use.

Link to this question

Which version of the RGIE is checked?

The Belgian RGIE, Book 1 (low and extra-low voltage installations), in force since 1/6/2020. Depending on the installation date entered, part by part, Voltaplan also applies the former RGIE (Royal Decree of 10 March 1981) or the rules for an old part (before 1/10/1981), as well as the dated amendments of Book 1. Symbols follow table 2.23 and the single-line diagram follows figure 3.1. Only part of the rules is checked, and they must be reviewed by a professional: the list and the open points are in the regulatory coverage (in French).

Link to this question

New or existing installation?

Both. For a new installation, you design the installation: all rules apply and non-compliances are blocking for the inspection file. For an existing installation (sale, upgrade), you survey what is in place: what is not seen stays “unknown” and is not counted as missing; safety rules remain blocking, the others become recommendations. An installation can mix parts from several periods.

Link to this question

What about other countries?

Today, only the Belgian RGIE is available. The engine is designed for other countries (one country = one rules module, with its texts and lists), but no other regulation is included yet.

Features

How are cable lengths estimated?

From the layout plan: from the board to the points in diagram order, at right angles, with rises and drops according to mounting height (switch at 1.10 m, low socket at 0.25 m…), changes of floor and a 10 % margin. Condui cable traces are reused; for other imports, right-angle traces are created from the single-line diagram, shown as dashed lines, to adjust. A length you entered is never replaced. See Cable lengths.

Link to this question

How do I print the file?

Print / PDF (Ctrl+P): working document, inspection file, anomaly report or complete technical file, in A4 or A3 landscape, with the parts of your choice (single-line diagram, plans, boards, legend, measurements, bill of materials, 1:1 labels…). Choose “Save as PDF” in the print dialog for a vector PDF. The inspection file carries a “DRAFT — …” mark while points remain to be dealt with. See Printing the file.

AI and privacy

Is the AI required?

No. Everything works without AI; it is off by default and each use must be allowed. If you turn it on, it goes through the provider you choose with your own key (Anthropic, or an OpenAI-compatible API: OpenAI, Gemini, Mistral), or through a local model (Ollama, LM Studio) with no key, in which case nothing leaves the computer. Only the photo concerned (board, meter plate or plan) is sent, directly from your device to the provider, never the customer's name or address. Any cost is yours. See AI and the privacy policy.

Link to this question

Is there any telemetry or audience tracking?

No: no telemetry, no statistics, no cookies or trackers added by Voltaplan. Only the website host (GitHub Pages) receives the usual requests to download the app, as for any website.

The project

How do I report a bug or contribute?

Open an issue on the GitHub repository. Issues are public: never attach a customer's file, photo or address. Report a security vulnerability through a private report. Code, rules, translations and tests are welcome: see the contribution guide (a regulatory contribution cites its source; a contributor agreement is required before the first contribution).

Link to this question

How can I support Voltaplan?

With an optional donation on GitHub Sponsors: it funds development, maintenance and regulatory review time, and unlocks nothing. Reporting a bug or having a rule reviewed by a professional helps just as much.
