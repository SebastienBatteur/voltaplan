Getting started

The simplest way: open the app in your browser (app/). It can be installed like an application (the “Install” icon in the Chrome or Edge address bar) and then works offline.

  1. New creates an empty project with an origin (the supply), or Import Trikker picks up an existing file.
  2. Fill in the Project tab: address, installer, voltage, EAN, type of installation (new or existing).
  3. Add the distribution board, RCDs, circuits and points in the tree on the left; the single-line diagram draws itself.
  4. Place the points on the Floor plan, arrange the devices in the Board, then click ⟳ Update.
  5. Fix whatever the RGIE check reports, then Print / PDF.

Voltaplan is an aid: it replaces neither the official text of the RGIE (Belgian electrical installation regulations, Book 1) nor the opinion of the approved inspection body.

The screen

  • Top bar: File menu (new, open, import Trikker, save, save as, print / PDF), Save button (blue when there are unsaved changes), ⟳ Update, undo / redo, tabs, language (FR, NL, EN).
  • Tabs: Single-line, Floor plan, Board, Materials, Project, RGIE check (the red number = number of non-conformities).
  • On the left: the installation tree and the properties of the selected element. The ‹ button hides the whole column (› brings it back). Click the “Installation” or “Properties” heading to collapse that part; drag the line between them to share the height, and the right edge of the column to widen it. The layout is remembered on this computer.
  • Linked selection: an element chosen in the tree, the single-line diagram, the plan or the board is selected everywhere. Its whole chain lights up in orange: everything feeding it back to the meter and everything it feeds; the rest of the diagram fades.
  • Moving around: dragging from an empty area pans the whole diagram, plan or board (on the single-line diagram, drag anywhere). Long press (half a second without moving, with the mouse or a finger) then drag: pans the whole view even when starting on a symbol, wall or device. A quick drag on an element moves that element. Mouse wheel = zoom, “Fit” = see everything.

Describing the installation

The installation is a tree: origin → (meter) → protective devices → distribution board → RCDs → circuit breakers → cables → points (sockets, switches, light points, appliances…).

Adding an element — three ways, each offering only what can be connected under the chosen element:

  1. Right-click a symbol on the single-line diagram (e.g. a circuit breaker) → “Add to” → Cable;
  2. the ＋ at the end of a tree row (shown on hover or on the selected row);
  3. the ＋ Add… button at the top of the properties.

The new element is selected: fill in its properties. Example for a socket circuit: right-click the board → Protection (20 A circuit breaker); then on that circuit breaker → Cable (VOB 3G2.5); then on the cable → Socket, as many times as needed. Finally, ⟳ Update puts the circuit breaker in the board and the sockets on the plan.

  • Protection: device (circuit breaker / MCB, RCD, RCBO, fuse, switch-disconnector), rating, poles, curve, breaking capacity, RCD sensitivity and type, number of modules, manufacturer reference, “old part” (installed before 1 October 1981).
  • Cable: type (VOB, XVB…), cross-section, number of conductors, in conduit, installation method, length (needed for the calculations).
  • Location: the room (e.g. “Kitchen”). It is used to place the points on the plan next to the room name.
  • RGIE numbering (3.1.2.1): circuits A, B, C…; points A1, A2… in order from the protective device; a switch takes the number of the point it controls. A letter can be forced.

Single-line diagram

Drawn automatically from bottom to top (supply at the bottom, as in figure 3.1 of the RGIE); the “Direction” button switches to top → bottom. The symbols follow table 2.23 of the RGIE; the legend of the symbols used is printed with the file. A red or orange dot on a symbol = a finding from the check.

Layout plan

  • Walls (right angles, snapped ends, dimensions), doors, double doors, French windows, sliding patio doors, windows, room names, several pages (floors).
  • Editing a door or window: click it (the opening, the leaf or the swing arc), then in the panel: type (door, double door, French window, sliding patio door, window…), width, Open to the other side and Hinge on the other end; for a sliding door, Slide the other way. Clicking elsewhere deselects it.
  • Background: photo or PDF. Set scale: click two points and enter their real distance. Straighten: click the 4 corners of a known rectangle on a photo taken at an angle. Trace walls: automatic detection of walls, doors and windows, to be checked. Align background: overlay a recent photo on the plan to see what has changed.
  • Furniture: pictograms to scale (beds, sofa, kitchen, bathroom fittings…). Furniture imported from Trikker (images) can be selected too: drag to move, width, depth, angle, 90° rotation, duplicate, delete, or Replace with a pictogram (same place, same size).
  • Electrical symbols: “Place on plan” from the properties, then drag, rotate, remove.

Distribution board

DIN rows (number of rows and modules per row in the board's properties). Devices have their real width: a 1P+N circuit breaker can be 1 or 2 modules depending on the range, a 2P circuit breaker is 2, a 4P RCD is 4 — set this in “Width (modules)”. Drag and drop between rows and the reserve; “Automatic layout” arranges everything in tree order. Labels (reference + use) print at 1:1 scale.

Board photo

  1. “Board photo…”: choose a photo taken from the front.
  2. “Align photo (rows)”: for each row, click the left edge of the first module, then the end of the row, at mid-height of the devices.
  3. “Arrange from photo”: without AI, Voltaplan finds the occupied modules on each row (a blanking cover is uniform, a bare rail darker) and the gaps between devices, then places the project's devices there: first those of 2 modules or more, where the photo shows a device of that width; then the single-module ones, in order, on the remaining occupied modules. Anything that does not fit stays in the reserve, and positions occupied on the photo with no matching project device are flagged. This is a suggestion: the photo shows neither type nor rating; check and move devices with the mouse (“Undo” goes back).
  4. “Compare with photo”: without AI, Voltaplan measures the gaps between devices and flags those whose width does not match (e.g. 1 module in the project, 2 on the photo). The drawn devices become transparent so you can compare by eye.
  5. Optionally, the AI reads the ratings, curves and sensitivities, arranges the devices in place and compares them with the project (see AI).

Update (new installation, added circuits)

After creating the installation or adding circuits, click ⟳ Update:

  • new devices are placed in the first free position in the board, without moving the others (a board that was never laid out is arranged entirely); if there is no room left, you are told;
  • new points are placed on the plan next to their room name; the others go into a “to place” column to the left of the plan;
  • a revision is added to the file with the list of added circuits (RGIE 3.1.2: an extension must be recorded on the drawings);
  • numbering, labels, bill of materials and check are recalculated.

“Undo” in the result window reverts everything in one step.

Bill of materials

Materials tab: materials are grouped by category and totalled (pieces, cable runs and total cable length). Items are described by their characteristics and European standard (e.g. “Circuit breaker 2P C20 A 3 kA — EN 60898-1”): manufacturer references, and even product ranges, differ from one country to another. Cables keep their national designation with the harmonised equivalent where one exists (VOB ≈ H07V-U/R). A manufacturer reference can be added to each element. CSV export for Excel; a “Bill of materials” page in the printed file.

RGIE check

The type of installation decides how strict it is:

ProjectNon-conformity
New installation, current RGIEblocking; the printed file is marked “DRAFT — NOT COMPLIANT”
Existing installation or old RGIEnon-blocking warning + advice on bringing it into compliance

Rules checked include: mandatory information in the file, earthing and measurements, main RCD and 30 mA RCDs (wet rooms, washing machine…), selectivity, cross-section ↔ rating, number of sockets per circuit, dedicated circuits, child protection and earthing of sockets, double-pole circuit breakers on a 3 × 230 V network, voltage drop and short-circuit. Click a finding to select the element.

Voltage drop and short-circuit

At the bottom of the Check tab, a table gives for each circuit: length to the furthest point, cross-section, voltage drop, minimum short-circuit current and maximum protected length. Conventional IEC 60364 method: copper ρ = 0.0225 Ω·mm²/m, current = rating of the protective device, 80 % of the voltage for the short-circuit; limits 3 % (lighting) and 5 % (other). Fill in the length of each cable to get the values.

Measurements

Project tab: earth resistance, insulation, equipotential bonding, test of each RCD (tripping time ≤ 300 ms, 500 ms for an “S” type, circuits covered), date and test instrument. They are checked and printed on the “Measurements” page.

Printing the file

Print / PDF (Ctrl+P): A4 or A3 landscape, choice of sections (single-line diagram, plans, boards, circuits, legend, measurements, bill of materials, 1:1 labels, findings). Every page has the title block: version and date, installer (name, qualification, VAT number), address, voltage, EAN, signature boxes. In the print dialog, choose “Save as PDF” for a vector PDF. For labels, print at 100 % (no “fit to page”).

Drive, OneDrive, Dropbox

Voltaplan talks to the service directly from your browser; there is no Voltaplan server in between. Each service requires you to register the application once to get an ID (public, not a secret). The redirect address to register is shown in Voltaplan (Save as… → Drive, OneDrive, Dropbox): it is the app's address followed by oauth.html.

  • OneDrive: entra.microsoft.com → App registrations → New registration; accounts in any directory and personal Microsoft accounts; platform Single-page application (SPA) with the redirect address; Microsoft Graph permission Files.ReadWrite.AppFolder. Copy the “Application (client) ID”.
  • Dropbox: dropbox.com/developers/apps → Create app; Scoped access, App folder; Permissions tab: files.content.read and files.content.write; Settings tab: Redirect URI. Copy the “App key”.
  • Google Drive: console.cloud.google.com → enable the Google Drive API; OAuth consent screen; Credentials → OAuth client ID of type Web application, JavaScript origin = the site's address, redirect URI = the address of oauth.html; scope drive.file. Copy the “Client ID”.

Paste the ID into Voltaplan, then “List projects” or “Save here”: a window from the service opens so you can sign in. The token is kept in memory for the session only. For a published build, the ID can be set at build time (VITE_ONEDRIVE_CLIENT_ID, VITE_DROPBOX_CLIENT_ID, VITE_GOOGLE_CLIENT_ID).

Trikker

Import Trikker (.trik) brings in the diagram, numbering, plan (walls, openings, rooms, images), addresses and notes. Save as… → This device → Export for Trikker (.trik) produces a Trikker file (Windows-1252, like Trikker).

AI (optional)

Everything works without AI, including “Arrange from photo”, which analyses the image on your computer. For now the AI adds just one thing: reading the markings on the devices in the board photo (type, rating, curve, sensitivity, RCD type, label), then arranging the project's devices in place and comparing them. It uses the Anthropic API (Claude models) with your own key: Voltaplan has no server and never sees your photos or your key.

1. Get an Anthropic API key

  1. Create an account at console.anthropic.com (email address or Google account).
  2. Billing: add a payment method and buy credits. The API is pay-as-you-go, separate from any Claude.ai subscription.
  3. Recommended: under Limits, set a low monthly spend limit. A stolen key or a mistake can then never cost more than that limit.
  4. API Keys → Create Key; give it a name (e.g. “Voltaplan – my PC”). The key starts with sk-ant- and is shown only once: copy it straight away.

The price depends on the model and the size of the photo; it is published at anthropic.com/pricing. Each reading is one request (one photo and a short instruction); the actual cost appears in the console under Usage.

2. Set up Voltaplan

  1. Click ⚙ AI in the top bar and tick Use AI.
  2. Model: claude-opus-5-5 by default (the most accurate at reading small markings). You can enter another Claude model ID, faster or cheaper, at the cost of less reliable reading.
  3. New key: paste the sk-ant-… key.
  4. Passphrase (8 characters minimum), then Encrypt and save.
  5. Under What the AI may generate, tick Module layout from a photo of the board. Nothing is ticked to begin with. The other boxes (plan from a photo, single-line diagram from an old file, fix suggestions) are planned but not active yet.

3. Read a board photo

  1. Board tab: import the photo and align it (row by row) as described in Board photo.
  2. Click Read photo (AI). This button only appears if AI is enabled and allowed for the board.
  3. If the key is locked (after reloading the page, for example), Voltaplan asks for the passphrase next to the button; reading starts as soon as it is entered. You only need to do this once per session. A counter shows the seconds elapsed while reading.
  4. Voltaplan arranges the project's devices in the positions read, including those in reserve: each device on the photo gets the project device that matches it best (type, rating, sensitivity, curve, label, then tree order). The AI also reads the brand and model and measures the width on the ruler: the width read becomes the device's width (a compact 4-pole device can be 2 modules wide) and the model fills in the reference if it is empty. A device is only placed where the photo shows a device of the same type (never a breaker in place of a meter); whatever does not fit stays in reserve. Relays, impulse relays, contactors, time switches, transformers, meters and home-automation modules from the single-line diagram count as board devices when « In the board » is ticked in their properties (ticked by default for relays and meters). For a device seen on the photo but missing from the project, the « Link to… » menu in the list offers the elements of this board: choosing one ticks « In the board », takes the width and reference read, and places it where it was seen. For a breaker or RCD missing from the single-line diagram, « ＋ New… » creates it under the board with what was read (rating, curve, width, reference): then move it under its RCD in the tree. Identical devices the photo cannot tell apart (for example three 40 A 30 mA RCDs) are placed in single-line diagram order, left to right. Ctrl+Z undoes it.
  5. The result then lists the differences with the project (missing device, width, type, rating, curve, sensitivity, uncertain reading). It is an automatic reading that must be checked: confirm each device with its badge. Only the layout changes; device characteristics are never modified.

What is sent, and where

Sent to Anthropicthe aligned board photo, the number of rows and modules per row, and the interface language. Nothing else: not the customer's name or address, nor the rest of the project.
Howdirectly from your browser (or the desktop app) to api.anthropic.com, over HTTPS, with no intermediary.
Stored keyencrypted (256-bit AES-GCM, key derived from the passphrase with PBKDF2-SHA-256) in the local storage of this browser or app. Never in the .voltaplan file, nor in any file sent to a customer or an approved inspection body.
Passphraseis not stored anywhere. The decrypted key stays in memory until the tab or the app is closed.
On Anthropic's sidedata sent to the API is covered by Anthropic's commercial terms, which by default exclude its use for training models.

Changing or removing the key

  • Forgotten passphrase: the key cannot be recovered. Click Delete key, then save a new one.
  • New key: Delete key, then paste the new one.
  • Compromised key (lost computer, key copied by mistake): disable it in the Anthropic console under API Keys. It stops working everywhere immediately.
  • Another computer or browser: the key is not there. Set it up again; you can reuse the same key or create one per workstation.

Troubleshooting

“The AI declined…”the photo was not processed. Try a sharper photo that shows only the board.

For developers

The code is in src/ai/:

  • settings.ts: settings and permissions, all disabled by default;
  • secureStore.ts: the encrypted key vault;
  • boardPhoto.ts: comparison of the reading with the project;
  • boardPhotoAi.ts: the API call with the official @anthropic-ai/sdk SDK, loaded only on first use.

The response is constrained by a schema (structured output): rows → devices with position, width, type, rating, curve, sensitivity, label and confidence level. Any new AI feature must have its own permission box, disabled by default, and must never send personal project data without the user knowing.

Countries and regulations

The Belgian RGIE is the default standard (Project tab → Standard). The engine is designed for other countries: one country = one rules module, with its texts and lists (cable designations…), without changing the rest of the application. A designation that does not exist in the project's country is flagged.

Privacy

Voltaplan has no server. Projects (including customers' names and addresses) stay on your computer or in the storage you choose. No account, no tracking, no ads.
