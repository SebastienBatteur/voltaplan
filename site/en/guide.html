Getting started

The simplest way: open the app in your browser (app/). It can be installed like an application (the “Install” icon in the Chrome or Edge address bar) and then works offline.

  1. On the My projects screen (see below), create a New project, or use Import from other software to pick up an existing file (see Import).
  2. Fill in the Project tab: address, installer, voltage, EAN, type of installation (new or existing). Read the meter plate (photo)… reads the voltage and number of phases from a photo of the meter plate, on this device, and suggests the supply.
  3. Add the distribution board, RCDs, circuits and points in the tree on the left; the single-line diagram draws itself.
  4. Place the points on the Floor plan, arrange the devices in the Board, then click ⟳ Update.
  5. Fix whatever the RGIE check reports, then Print / PDF.

Voltaplan is an aid: it replaces neither the official text of the RGIE (Belgian electrical installation regulations, Book 1) nor the opinion of the approved inspection body.

My projects: when it opens, Voltaplan shows the main actions (New project, Survey an existing installation, Open a file, Open from the cloud or the browser, Import from other software) and your latest projects; one click reopens them. Come back with File → My projects (home) or by clicking the logo. A new project takes 4 short steps (type, address and client, installer, supply), each optional. For a new installation you can start from a typical house: lighting, sockets, cooker, bathroom and washing machine under a 30 mA RCD, and earthing are already in place; then adapt it.

The screen

  • Top bar: File menu (My projects (home), New, New survey (existing installation), Open…, Import from other software…, Save, Save as…, Local versions…, Survey assistant (experimental)…, Print / PDF), Save button (blue when there are unsaved changes), ⟳ Update, undo / redo, tabs, ⚙ AI, language (French, Dutch, English, German). On a small screen, undo, redo, Update, AI and the language move to the “⋯” menu.
  • Tabs: Single-line, Floor plan, Board, Materials, Project, RGIE check (the red number = number of non-conformities).
  • On the left: the installation tree and the properties of the selected element. The ‹ button hides the whole column (› brings it back). Click the “Installation” or “Properties” heading to collapse that part; drag the line between them to share the height, and the right edge of the column to widen it. The layout is remembered on this computer.
  • Elements (below “Properties”): the palette. On the single-line diagram, tree or board: single-line elements by family (boards and protections, wiring, lighting, sockets and appliances, controls, home automation and misc.); a click adds the element under the selected one (greyed if it cannot connect there). On the plan: the tools (walls, doors, windows, texts, furniture by room), single-line elements to drop at the next click, and Not yet on the plan: what remains to be placed, grouped by circuit.
  • Linked selection: an element chosen in the tree, the single-line diagram, the plan or the board is selected everywhere. Its whole chain lights up in orange: everything feeding it back to the meter and everything it feeds; the rest of the diagram fades.
  • Moving around: dragging from an empty area pans the whole diagram, plan or board (on the single-line diagram, drag anywhere). Long press (half a second without moving, with the mouse or a finger) then drag: pans the whole view even when starting on a symbol, wall or device. A quick drag on an element moves that element. Mouse wheel = zoom, “Fit” = see everything.

Describing the installation

The installation is a tree: origin → (meter) → protective devices → distribution board → RCDs → circuit breakers → cables → points (sockets, switches, light points, appliances…).

Adding an element — several ways, each offering only what can be connected under the chosen element:

  1. Right-click a symbol on the single-line diagram (e.g. a circuit breaker) → “Add to” → Cable;
  2. the ＋ at the end of a tree row (shown on hover or on the selected row);
  3. the ＋ Add… button at the top of the properties;
  4. the Elements palette in the left column;
  5. on the plan, a right-click where the element is: choose the element, then its position in the single-line diagram (under which cable, which switch…, or a new circuit of a board). Voltaplan suggests the circuit of the nearest element on the plan. The element is added to the single-line diagram and placed on the plan where you clicked.

Protection in series: a breaker's ＋ Protection in series button adds, just below it, a second protection that takes over its cables, for example a connected breaker with metering (EARU, Zigbee) behind the circuit breaker. It stays in the same circuit: no new letter, point numbering unchanged. Give it the set threshold as rating, at most that of the breaker above.

The new element is selected: fill in its properties. Example for a socket circuit: right-click the board → Protection (20 A circuit breaker); then on that circuit breaker → Cable (VOB 3G2.5); then on the cable → Socket, as many times as needed. Finally, ⟳ Update puts the circuit breaker in the board and the sockets on the plan.

  • Protection: device (circuit breaker / MCB, RCD, RCBO, fuse, switch-disconnector), rating, poles, curve, breaking capacity, RCD sensitivity and type, number of modules, manufacturer reference, “old part” (installed before 1 October 1981).
  • Cable: type (VOB, XVB…), cross-section, number of conductors, in conduit, installation method, length (for the voltage drop and the bill of materials; entered, or estimated from the plan: see Cable lengths).
  • Location: the room (e.g. “Kitchen”). It is used to place the points on the plan next to the room name.
  • RGIE numbering (3.1.2.1): circuits A, B, C…; points A1, A2… in order from the protective device; a switch takes the number of the point it controls. A letter can be forced.

Single-line diagram

Drawn automatically from bottom to top (supply at the bottom, as in figure 3.1 of the RGIE); the “Direction” button switches to top → bottom. The symbols follow table 2.23 of the RGIE; the legend of the symbols used is printed with the file. A red or orange dot on a symbol = a finding from the check.

Layout plan

  • Walls (right angles, snapped ends, dimensions), doors, double doors, French windows, sliding patio doors, windows, room names, several pages (floors).
  • Editing a door or window: click it (the opening, the leaf or the swing arc), then in the panel: type (door, double door, French window, sliding patio door, window…), width, Open to the other side and Hinge on the other end; for a sliding door, Slide the other way. Clicking elsewhere deselects it.
  • Background: photo or PDF. Set scale: click two points and enter their real distance. Straighten: click the 4 corners of a known rectangle on a photo taken at an angle. Trace walls: automatic detection of walls, doors and windows, to be checked. Align background: overlay a recent photo on the plan to see what has changed.
  • Read room names: reads the room names written on the background plan (on this device, no image sent) and places them on the plan, to be checked.
  • Equip the room: select a room name (bedroom, kitchen, bathroom…); Voltaplan offers the usual equipment for that type of room, to tick, and typical furniture. The points are placed in position but not connected: link them to their circuits afterwards. It is not an RGIE list, just a starting point (Ctrl+Z undoes it).
  • Cable traces: traces taken over from an import (Condui) or created from the single-line diagram are drawn as dashed lines; those created automatically are paler and need adjusting (see Cable lengths).
  • Furniture: pictograms to scale (beds, sofa, kitchen, bathroom fittings…). Furniture imported from other software as images (Trikker) can be selected too: drag to move, width, depth, angle, 90° rotation, duplicate, delete, or Replace with a pictogram (same place, same size).
  • Electrical symbols: “Place on plan” from the properties or from the palette's Not yet on the plan list, or right-click on the plan to add a new one; then drag, rotate, remove. Ceiling lights, fluorescent tubes, appliances, motors and square elements are drawn without a connection stroke. Sockets, switches, push buttons, bells and wall lights keep their small stroke, turned automatically towards the nearest wall (it follows when they or the wall move); “Face the walls” applies it to the elements of an imported plan, and rotating an element by hand stops its automatic orientation.
  • DXF plan (AutoCAD, ArchiCAD, LibreCAD…): through Background plan (photo / PDF / DXF). A DXF that states its unit is placed to scale straight away; otherwise use Set scale. Save a “binary” DXF as text (ASCII) DXF first.
  • Circuit colours: each circuit gets a colour on the plan and the diagram, with a legend. The printed file stays black.
  • Converters: choose the type (inverter DC → AC, rectifier/inverter AC ↔ DC for a home battery, chopper DC → DC); the symbols follow table 2.23 of the RGIE.

Distribution board

DIN rows (number of rows and modules per row in the board's properties). Devices have their real width: a 1P+N circuit breaker can be 1 or 2 modules depending on the range, a 2P circuit breaker is 2, a 4P RCD is 4 — set this in “Width (modules)”. Drag and drop between rows and the reserve; “Automatic layout” arranges everything in tree order. Labels (reference + use) print at 1:1 scale.

Board photo

  1. “Board photo…”: choose a photo taken from the front.
  2. “Align photo (rows)”: for each row, click the left edge of the first module, then the end of the row, at mid-height of the devices.
  3. “Arrange from photo”: without AI, Voltaplan finds the occupied modules on each row (a blanking cover is uniform, a bare rail darker) and the gaps between devices, then places the project's devices there. A device already placed (by hand or by the AI) keeps its position if the photo shows a device there; protections go before relays and home-automation modules. Then: first those of 2 modules or more, where the photo shows a device of that width; then the single-module ones, in order, on the remaining occupied modules. Anything that does not fit stays in the reserve, and positions occupied on the photo with no matching project device are listed, each with a “Link to…” menu offering every element of this board's single-line diagram, or “＋ New breaker”. This is a suggestion: the photo shows neither type nor rating; check and move devices with the mouse (“Undo” goes back).
  4. “Compare with photo”: without AI, Voltaplan measures the gaps between devices and flags those whose width does not match (e.g. 1 module in the project, 2 on the photo). The drawn devices become transparent so you can compare by eye.
  5. “Read the photo”: without AI, a local reading (on this device, no image sent) cuts out the devices and reads the labels, ratings and sensitivities that are legible; they are proposed with low confidence, to be checked. Local reading is reliable for printed labels, less so for the ratings of small modules on a photo of the whole board. When the AI is set up and unlocked, the same button becomes “Read photo (AI)”: the AI reads the ratings, curves and sensitivities, arranges the devices in place and compares them with the project (see AI).

Update (new installation, added circuits)

After creating the installation or adding circuits, click ⟳ Update:

  • new devices are placed in the first free position in the board, without moving the others (a board that was never laid out is arranged entirely); if there is no room left, you are told;
  • new points are placed on the plan next to their room name; the others go into a “to place” column to the left of the plan;
  • cable lengths are estimated from the plan (see Cable lengths);
  • a revision is added to the file with the list of added circuits (RGIE 3.1.2: an extension must be recorded on the drawings);
  • numbering, labels, bill of materials and check are recalculated.

“Undo” in the result window reverts everything in one step.

Cable lengths

⟳ Update and the Estimate lengths button (Materials tab) estimate the length of each cable from the layout plan: from the board to the first point, then from point to point in diagram order, at right angles, with a 10 % margin. Place the board on the plan: without it, the run is counted from the first point and is too short (you are told).

  • Rises and drops according to mounting height: switch and push button at hand height (1.10 m) fed from the ceiling, pull-cord switch at the top (2.30 m), low socket (0.25 m) fed from below, wall light at 1.90 m; changes of floor are counted.
  • Cable traces: traces taken over from Condui (point to point through the waypoints) are drawn as dashed lines and followed by the estimate; the run from the board, which Condui does not trace, is still estimated. For an import without traces (PDF, Trikker, Volter, Draadwijs, PlanElec, Eendraadschema, untraced Condui circuits), right-angle traces are created from the single-line diagram, from the board to the first point and then from point to point; they are drawn paler and marked “to adjust”.
  • An estimated length is marked Length estimated from the plan in the properties and “≈” in the bill of materials. A length you entered is never replaced, and entering one removes the mark.

The RGIE only requires cable lengths on the diagram for a non-domestic installation; for a domestic one, type, cross-section, number of conductors and installation method are enough. The length is mainly used for the voltage drop and the bill of materials.

Bill of materials

Materials tab: materials are grouped by category and totalled (pieces, cable runs and total cable length). Items are described by their characteristics and European standard (e.g. “Circuit breaker 2P C20 A 3 kA — EN 60898-1”): manufacturer references, and even product ranges, differ from one country to another. Cables keep their national designation with the harmonised equivalent where one exists (VOB ≈ H07V-U/R). A manufacturer reference can be added to each element. CSV export for a spreadsheet; a “Bill of materials” page in the printed file. Circuit list (CSV): letter, name, protection, RCD, cable, number of points and rooms of each circuit, as in the PDF file. Estimate lengths: see Cable lengths.

The By room button sorts the materials room by room (from each element's location or its room on the plan), handy for the job or a quote.

RGIE check

A checking aid: it replaces neither the RGIE text nor the inspection by an approved body. Each finding has a status, a hazard level (high, moderate, low) and, where relevant, the blocking mark.

StatusMeaning
Non-compliance detectednon-compliance with the applicable RGIE edition; blocking for a new part, and for an existing part when the hazard is high (earthing, RCD, cable protection…)
Insufficient informationrequired data missing or unknown (rating, cross-section, sensitivity…)
Potential anomalybased on deduced or unconfirmed information (for example a value read from a photo)
Contradictory informationthe drawing and a declaration (or two sources) disagree
Warningpoint to examine (estimated voltage drop, selectivity…)
Manual check requiredon-site check or interpretation (wet room guessed from the room name, EV charger, photovoltaics, measurements)
Recommendationupgrade advised, not required for an existing part
Derogationfinding covered by a derogation you entered with its reason

Existing installation: an element missing from the drawing is not assumed to be missing from the real installation. An earth electrode, main RCD or 30 mA RCD that is not drawn gives “Insufficient information”, not blocking, with the buttons Confirm present, Confirm absent and I don’t know. A confirmed absence gives a non-compliance again. For a new installation, the drawing remains the reference. Documentary requirements (file information, values not filled in) are shown separately, never as non-compliances of the installation.

RGIE edition: in the Project tab, enter the installation date (“1995”, “2024-03-15”). Before 1/10/1981: old part; until 31/5/2020: former RGIE (Royal Decree of 10 March 1981); since 1/6/2020: Book 1. An installation often mixes several generations: in the properties of a board or breaker, Installed on and New or existing part apply the rules of its time to that part only (a circuit added in 2024 to a 1990 installation follows Book 1). Dated amendments of Book 1 are applied according to the start date of the work: for example, since 1/3/2025, sockets of at most 16 A with shutters (IPXX-D), except a socket reserved for a specific appliance.

Bathroom: set Room with bath or shower (yes / no) in the circuit or point properties. A suggestive room name (“bathroom”, “shower”) is only a hint, reported as “To check”.

Derogation: Derogation… button under a finding, with a required reason and a reference (article, inspection report). The finding is no longer blocking but stays visible, with its reason, in the panel and the printed file. The Single-line, Plan and Board buttons of a finding open the element in that view. When the fix is obvious, a button under the finding offers it (for example “Choose 20 A”, “Socket with shutters”, “Type A RCD”); “Undo” reverts it. Missing file information leads to the Project tab.

Rules checked include: mandatory file information, earthing and measurements, main and 30 mA RCDs (wet rooms, washing machine…), selectivity, cross-section ↔ rating, sockets per circuit, dedicated circuits, child safety and earthing of sockets, two-pole breakers on 3 × 230 V networks, voltage drop and short-circuit. Details and points awaiting expert review are in the regulatory coverage.

Voltage drop and short-circuit

At the bottom of the Check tab, a table gives for each circuit: length to the furthest point, cross-section, voltage drop, minimum short-circuit current and maximum protected length. Conventional IEC 60364 method (an estimate, not a protection study): ρ = 0.0225 Ω·mm²/m for copper (0.036 for aluminium), current = rating of the protective device, 80 % of the voltage for the short-circuit; limits 3 % (lighting) and 5 % (other). If every load has a power, the drop is also calculated with the actual current. The length of each cable is needed: entered, or estimated from the plan (see Cable lengths).

Measurements

Project tab: earth resistance, insulation, equipotential bonding, test of each RCD (tripping time ≤ 300 ms, 500 ms for an “S” type, circuits covered), date and test instrument. They are checked and printed on the “Measurements” page.

Printing the file

Print / PDF (Ctrl+P): first choose the document type. Working document: always printable, even with anomalies. Inspection file: for the approved body; marked “DRAFT — NON-COMPLIANCES TO ADDRESS”, “DRAFT — CHECKS TO DO” or “DRAFT — INCOMPLETE FILE” while points remain to be dealt with. Anomaly report: all findings, the circuit list and the measurements. Complete technical file: all parts. Then: A4 or A3 landscape and the parts to include (single-line, plans, boards, circuits, legend, measurements, bill of materials, 1:1 labels, findings). Each page has the title block: document type, file number, version and date, installer (name, capacity, VAT), address, voltage, EAN, signature boxes. In the print dialog, choose “Save as PDF” for a vector PDF. For labels, print at 100 % (no “fit to page”).

QR labels for the board: 4 labels of 9 × 5.5 cm. With a link to the online file (Project tab, e.g. a Drive or OneDrive share link) the QR code opens that file; without one it holds the essentials (address, installer, phone, file number), readable offline. Voltaplan hosts nothing. File status (Project tab): In progress, Ready for inspection or Inspected.

Working together

Voltaplan has no team account: you simply share the project file, ideally in a shared folder (Drive, OneDrive, Dropbox or a network drive), opened with This device or the desktop app. One person edits at a time. If the file changed elsewhere since your last save, Voltaplan overwrites nothing: it warns you and keeps your version. Someone who only needs to read gets the PDF file.

Drive, OneDrive, Dropbox

Voltaplan talks to the service directly from your browser; there is no Voltaplan server in between. Each service requires you to register the application once to get an ID (public, not a secret). The redirect address to register is shown in Voltaplan (Save as… → Drive, OneDrive, Dropbox): it is the app's address followed by oauth.html.

  • OneDrive: entra.microsoft.com → App registrations → New registration; accounts in any directory and personal Microsoft accounts; platform Single-page application (SPA) with the redirect address; Microsoft Graph permission Files.ReadWrite.AppFolder. Copy the “Application (client) ID”.
  • Dropbox: dropbox.com/developers/apps → Create app; Scoped access, App folder; Permissions tab: files.content.read and files.content.write; Settings tab: Redirect URI. Copy the “App key”.
  • Google Drive: console.cloud.google.com → enable the Google Drive API; OAuth consent screen; Credentials → OAuth client ID of type Web application, JavaScript origin = the site's address, redirect URI = the address of oauth.html; scope drive.file. Copy the “Client ID”.

Paste the ID into Voltaplan, then “List projects” or “Save here”: a window from the service opens so you can sign in. The token is kept in memory for the session only. For a published build, the ID can be set at build time (VITE_ONEDRIVE_CLIENT_ID, VITE_DROPBOX_CLIENT_ID, VITE_GOOGLE_CLIENT_ID).

Import from other software

A single entry: File → Import from other software…, or the Import from other software card on the My projects screen. Voltaplan recognises the source from the file's content, whatever its extension:

SourceWhat is taken over
Voltaplan projecteverything (the file is simply opened)
Trikker (.trik)diagram, numbering, plan (walls, openings, rooms, images), addresses and notes
Volter (.vschema)board, RCDs, breakers and cables, points, floors, walls, doors, windows, furniture, EAN and network; what Volter does not record (meter, earthing) is flagged
Eendraadschema (.eds)supply, boards, protections, cables, points and file details; the site plan is not taken over
Draadwijsdiagram, plan, measurements, network, address; the quote is not taken over
PlanElec Sketchdiagram, references, plan in metres and placed symbols

  • PDF file: read in the browser, with no upload and no AI; files in French, Dutch, English or German. Only PDFs containing text can be read: a scanned PDF, or one whose text is drawn as images, is refused with an explanation. What the text does not say (exact type of points, controls…) is flagged when the file opens.
  • A .zip archive containing one of these files is opened and the diagram file inside it is imported.
  • An unrecognised file is refused with a message explaining why (diagram from unrecognised software, or not an electrical diagram file) and listing the recognised formats.
  • Imports without cable traces get right-angle traces created from the single-line diagram, to adjust (see Cable lengths).
  • An imported file only appears in “Recent projects” once it has been saved.

To go back to Trikker or Eendraadschema: Save as… → This device → Export for Trikker (.trik) (Windows-1252, like Trikker) or Export to Eendraadschema (.eds).

AI (optional)

Everything works without AI, including “Arrange from photo” and the local readings (meter plate, room names on the plan, “Read the photo” on the board), done on your device without sending anything. The AI, off by default, can complement these readings, each use being allowed separately:

  • Board: reading the markings on the devices in the board photo (type, rating, curve, sensitivity, RCD type, label), then arranging the project's devices in place and comparing them;
  • Meter: voltage and phases from the photo of the plate, only when the local reading missed something;
  • Plan: electrical symbols and missed room names, from a photo or PDF of the plan, after the local reading; they are placed as unconnected elements, to be linked to their circuits.

The AI goes through the provider you choose — the Anthropic API (Claude models) by default, an OpenAI-compatible API, or a local model — with your own key: Voltaplan has no server and never sees your photos or your key.

1. Get an Anthropic API key

  1. Create an account at console.anthropic.com (email address or Google account).
  2. Billing: add a payment method and buy credits. The API is pay-as-you-go, separate from any Claude.ai subscription.
  3. Recommended: under Limits, set a low monthly spend limit. A stolen key or a mistake can then never cost more than that limit.
  4. API Keys → Create Key; give it a name (e.g. “Voltaplan – my PC”). The key starts with sk-ant- and is shown only once: copy it straight away.

The price depends on the model and the size of the photo; it is published at anthropic.com/pricing. Each reading is one request (one photo and a short instruction); the actual cost appears in the console under Usage.

2. Set up Voltaplan

  1. Click ⚙ AI in the top bar and tick Use AI.
  2. Model: claude-opus-5-5 by default (the most accurate at reading small markings). You can enter another Claude model ID, faster or cheaper, at the cost of less reliable reading.
  3. New key: paste the sk-ant-… key.
  4. Passphrase (8 characters minimum), then Encrypt and save.
  5. Under What the AI may generate, tick the uses you want: Module layout from a photo of the board, Meter (voltage and phases from the plate photo), Plan (room names and electrical symbols). Nothing is ticked to begin with. The two other boxes (single-line diagram from an old file, fix suggestions) are planned but not used yet.

3. Read a board photo

  1. Board tab: import the photo and align it (row by row) as described in Board photo.
  2. Click Read photo (AI). The button has this name when the AI is enabled, allowed for the board and ready; otherwise it is called “Read the photo” and does the local reading, without AI.
  3. If the key is locked (after reloading the page, for example), click the 🔒 padlock next to the button and enter the passphrase (or use ⚙ AI). You only need to do this once per session. The ⚙ AI button at the top right turns green while the key is unlocked: the AI is ready. A counter shows the seconds elapsed while reading.
  4. Voltaplan arranges the project's devices in the positions read, including those in reserve: each device on the photo gets the project device that matches it best (type, rating, sensitivity, curve, label, then tree order). The AI also reads the brand and model and measures the width on the ruler: the width read becomes the device's width (a compact 4-pole device can be 2 modules wide) and the model fills in the reference if it is empty. A device is only placed where the photo shows a device of the same type (never a breaker in place of a meter); whatever does not fit stays in reserve. Relays, impulse relays, contactors, time switches, transformers, meters and home-automation modules from the single-line diagram count as board devices when « In the board » is ticked in their properties (ticked by default for relays and meters). For a device seen on the photo but missing from the project, the « Link to… » menu in the list offers similar types first, then every other element of this board's single-line diagram: choosing one ticks « In the board », takes the width and reference read, and places it where it was seen. For a breaker or RCD missing from the single-line diagram, « ＋ New… » creates it under the board with what was read (rating, curve, width, reference). A connected breaker mounted behind a circuit's breaker (EARU…) is created with « ＋ In series under O »: a protection in series in the same circuit, reference taken over, placed where it was seen. Identical devices the photo cannot tell apart (for example three 40 A 30 mA RCDs) are placed in single-line diagram order, left to right, unless an RCD's label lists its circuits (« A-F », « G H I J », « K to M »): it is then matched to the RCD of the single-line diagram that protects those circuits. Write these references on your RCD labels before taking the photo. For breakers, the circuit letter marked on or below the device (« H ») is the best clue; otherwise the usage label is compared word by word (« SOCKETS I » goes to « Sockets I », not to « Sockets II »). The characteristics read complete the single-line diagram: an empty value read with certainty is filled in directly; a value that differs from the project, or is read with doubt, is listed under « Characteristics read on the photo, to confirm », with an Apply button (or Apply all). The single-line diagram is never changed without your consent. Ctrl+Z undoes it.
  5. The result then lists the differences with the project (missing device, width, type, rating, curve, sensitivity, uncertain reading). It is an automatic reading that must be checked: confirm each device with its badge. Only the layout changes; device characteristics are never modified.

Other providers and local models

In ⚙ AI, Provider: “Anthropic (Claude)” or “OpenAI-compatible API”. The latter works with OpenAI (https://api.openai.com/v1), Gemini (Google's OpenAI-compatible endpoint), Mistral, and local models running on your computer: Ollama (http://localhost:11434/v1) or LM Studio (http://localhost:1234/v1). With a local model, no key is needed and nothing leaves the computer. Choose a model that can read images. The service that will receive the photo is shown in the settings before anything is sent. Whatever the provider, the answer is checked: an incomplete or malformed answer is rejected and changes nothing.

What is sent, and where

Sent to the chosen providerfor the board: the aligned board photo, the number of rows and modules per row, and the interface language; for the meter or the plan (if you ticked those uses): the photo of the plate or the image of the plan. Nothing else: not the customer's name or address, nor the rest of the project.
Howdirectly from your browser (or the desktop app) to the provider (api.anthropic.com for Anthropic), over HTTPS, with no intermediary. With a local model, nothing leaves the computer.
Stored keyencrypted (256-bit AES-GCM, key derived from the passphrase with PBKDF2-SHA-256) in the local storage of this browser or app. Never in the .voltaplan file, nor in any file sent to a customer or an approved inspection body.
Passphraseis not stored anywhere. The decrypted key stays in memory until the tab or the app is closed.
On Anthropic's sidedata sent to the API is covered by Anthropic's commercial terms, which by default exclude its use for training models.

Changing or removing the key

  • Forgotten passphrase: the key cannot be recovered. Click Delete key, then save a new one.
  • New key: Delete key, then paste the new one.
  • Compromised key (lost computer, key copied by mistake): disable it in the Anthropic console under API Keys. It stops working everywhere immediately.
  • Another computer or browser: the key is not there. Transfer it with the QR code or link (see Other devices), or set it up again; you can reuse the same key or create one per workstation.

Troubleshooting

401 / authenticationwrong, revoked or badly copied key (extra space). Delete it and paste it again.
insufficient credit / 400 billingcredits used up or spend limit reached: see Billing and Limits in the console.
404 / modelunknown model ID: set it back to claude-opus-5-5 in ⚙ AI.
429 / 529too many requests or service overloaded: try again in a minute.
“The AI declined…”the photo was not processed. Try a sharper photo that shows only the board.

For developers

The code is in src/ai/:

  • settings.ts: settings and permissions, all disabled by default;
  • secureStore.ts: the encrypted key vault;
  • boardPhoto.ts: comparison of the reading with the project;
  • boardPhotoAi.ts: the API call with the official @anthropic-ai/sdk SDK, loaded only on first use;
  • provider.ts and photoAi.ts: the OpenAI-compatible providers and the meter and plan readings.

The response is constrained by a schema (structured output): rows → devices with position, width, type, rating, curve, sensitivity, label and confidence level. Any new AI feature must have its own permission box, disabled by default, and must never send personal project data without the user knowing.

Other devices

In the AI settings, Other devices section: scan the QR code with the phone, or Copy link and paste it on the other device (Receive: paste the link or code). The key travels encrypted; the other device asks for the passphrase. No server is involved.

Countries and regulations

The Belgian RGIE is the default standard (Project tab → Standard). The engine is designed for other countries: one country = one rules module, with its texts and lists (cable designations…), without changing the rest of the application. A designation that does not exist in the project's country is flagged.
