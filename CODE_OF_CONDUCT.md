# Code de conduite

Voltaplan réunit des électriciens, des développeurs, des enseignants et des particuliers. Pour que chacun puisse
contribuer :

- **Respect** : critiquez les idées et le code, jamais les personnes. Pas d'insulte, de harcèlement ni de
  discrimination.
- **Bienveillance envers les débutants** : beaucoup d'utilisateurs ne sont pas à l'aise avec l'informatique, et
  beaucoup de développeurs ne connaissent pas le RGIE. Expliquez.
- **Confidentialité** : ne publiez jamais de données d'un client ni d'une autre personne.
- **Honnêteté technique** : citez vos sources, signalez vos incertitudes, et ne présentez pas une hypothèse comme
  une règle.

**Signaler un comportement inacceptable** : contactez le mainteneur en privé, par le profil GitHub du propriétaire
du dépôt. Les signalements sont traités avec discrétion. Le mainteneur peut masquer, modifier ou supprimer des
contributions, et exclure temporairement ou définitivement un participant.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/), auquel on peut se référer pour
les cas non prévus.
